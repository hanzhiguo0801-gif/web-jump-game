# 跳一跳网页版小游戏

这是一个纯前端 HTML5 Canvas 小游戏，不需要安装依赖。

## 直接运行

双击打开 `index.html`，或把它拖到浏览器里即可开始玩。

玩法：

- 按住鼠标左键或空格键蓄力
- 松开后角色跳跃
- 落到下一个平台得分
- 跳空后点击“再来一局”重新开始

## 分享给朋友

最简单的方式：把整个 `jump-game` 文件夹压缩后发给朋友，对方解压后打开 `index.html`。

如果想发一个网页链接，可以把这个文件夹上传到任意静态网站托管服务，例如 GitHub Pages、Netlify 或 Vercel。这个项目没有构建步骤，上传后入口文件就是 `index.html`。
